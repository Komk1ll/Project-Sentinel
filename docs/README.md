# Project Sentinel - Documentation Hub

Welcome to the central documentation hub for **Project Sentinel**.

## Documentation Principle

> **Core Rule**: All project architecture decisions, technical designs, workflow guides, and game specifications **must reside in `/docs`**. Keep this documentation updated with every feature and architectural change.

## Structure

```
docs/
├── architecture/          # Architecture blueprints, engine bridges, systems
│   └── overview.md        # Technical architecture (Phaser + Three.js)
├── decisions/             # Architecture Decision Records (ADRs)
├── guides/                # Developer guides and onboarding
│   └── getting_started.md # Development setup and workflow
└── specs/                 # Game design, narrative, and technical specs
    ├── project_summary.md # Game summary, setting, and priorities
    ├── ТЗ_Project_Sentinel_v1.docx
    └── Каталог_моделей_Project_Sentinel_v1.docx
```

## Language Standard

All technical documentation, code comments, and ADRs must be written **strictly in English** to maintain consistency across the team and automated agent workflows.
